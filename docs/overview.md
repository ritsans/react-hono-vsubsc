# アプリ概要：サブスクリプション管理アプリ

ユーザーが契約している複数のサブスクリプションサービスを一元管理し、毎月・年間の支出や次回の支払時期を把握しやすくするWebアプリケーション。

登録したサービスを一覧で確認でき、料金・契約周期・次回請求日などをもとに、現在どのサービスにいくら支払っているのかを分かりやすく整理する。

単なる登録リストではなく、継続するサービスと見直したいサービスを判断しやすくし、不要なサブスクリプションの解約・整理を支援することを目的とする。

## 主要機能

* サブスク情報の登録・管理: 契約情報の追加・閲覧・編集・削除を行えます。

* サービス名のサジェスト: メジャーサービスの補完表示、公式リンクへの移動、ブランドアイコン表示をサポートします。

* 請求額の集計・換算: JPYとUSDを別々に集計し、ユーザーの要求時のみ外部APIを呼び出して円換算（概算）を行います。

* アラート通知: 更新日や無料期間終了が近いサブスクをダッシュボード上で通知します。

## 技術構成

* フロントエンド: React (Vite)

* バックエンド: Hono

* 認証: Better Auth

* メインDB: Neon (PostgreSQL)

* デプロイ環境: Cloudflare Workers

* アイコン取得: Logo.dev

## 設計・開発方針

* 追跡しやすいデータフロー: 「React操作 → API呼び出し → Hono処理 → Neon読み書き」というシンプルな構造を徹底し、コードの理解しやすさを重視します。

* データ分離とセキュリティ: セッション検証に基づき、他ユーザーのデータ閲覧・編集を厳格に防止します。
